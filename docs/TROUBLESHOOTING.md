# Troubleshooting

Start with `npm run doctor` (terminal) or **`/diagnostics`** (any device on the LAN) — both probe
llama.cpp, ComfyUI, the database, the image folder and the LAN token in one shot.

| Symptom                                                               | Probe                                                                    | Cause / fix                                                                                                                                     |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Reply never appears, no error                                         | `curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:8081/v1/models` | llama.cpp not running. Start `llama_models\chat_image.bat` (it also boots ComfyUI first, which matters on 8 GB VRAM).                           |
| First reply takes 10–30 s                                             | router log shows model load                                              | expected: router mode loads on demand, `--models-max 1` evicts the previous model                                                               |
| `400 prompt_outputs_failed_validation` from ComfyUI                   | the response body names the node                                         | an unfilled `{{PLACEHOLDER}}` or a model file that is not in that folder. `fillGraph` throws before the request for the placeholder case.       |
| Sampler sliders seem to do nothing                                    | `curl http://127.0.0.1:8081/props`                                       | router mode: `/props` returns `role: router`, `params: null`. Defaults live in `models-router.ini`; per-request overrides still go in the body. |
| "Cross-site POST form submissions are forbidden"                      | browser console                                                          | SvelteKit's CSRF check is off; ours lives in `hooks.server.ts` comparing `Origin` to `Host`. A proxy that rewrites `Host` will trip it.         |
| Phone loads the form but never gets in                                | response headers of `/login?token=…`                                     | cookie must arrive without `Secure` (we are on plain http). adapter-node reports https; do not reintroduce a `Secure` flag.                     |
| Phone gets 401 on a fresh browser                                     | `curl -H 'Cookie: …' http://<lan-ip>:4173/`                              | expected — open `/login?token=<CHATCHAT_TOKEN>` once per device.                                                                                |
| Build looks broken but `npm run build` succeeded                      | `netstat -ano \| grep :4173`                                             | a stale `node build` is serving an old bundle. `taskkill //PID <pid> //F` then start again.                                                     |
| `messages.some is not a function`                                     | stack points at `standardizePrompt`                                      | `convertToModelMessages` was not awaited.                                                                                                       |
| Tests fail with `Cannot find module '../config.js'`                   | —                                                                        | wrong relative depth; use `$lib/server/...` inside `src/lib/server`.                                                                            |
| ComfyUI smoke test says "You must enable either polling or websocket" | —                                                                        | `client.connect({ websocket: { enabled: true } })` — nested object, not a boolean.                                                              |
| Picture generation says "fetch failed" / hangs 10 s                   | `/diagnostics` → ComfyUI row                                             | ComfyUI not running. Start it **before** llama-server on an 8 GB card so it claims its CUDA context first.                                      |
| Picture generation is slow (~40 s) but works                          | ComfyUI log shows model load + low it/s                                  | the LLM is resident and the model is being streamed from RAM; close the chat model (`/api/unload`) or accept it.                                |
| `/api/images/inpaint` returns "Expected a multipart form"             | send the form from a browser or `node -e` with `FormData`                | `curl -F` from Git Bash mangles the boundary; undici (browser, Node) is fine.                                                                   |
| Progress bar never moves but the picture arrives                      | —                                                                        | the websocket to ComfyUI is blocked; generation is unaffected (`client.ts` waits 2 s, then continues without progress).                         |
| `curl /history` shape confuses a custom tool                          | `GET :8188/history`                                                      | ComfyUI answers a **map keyed by prompt id**; the client calls `Object.values()` on it. `fake-comfy.ts` mirrors that.                           |
